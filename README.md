# Microservicio de Identidad - Our Sour

## Descripción
Microservicio responsable de la autenticación, autorización y gestión de cuentas y roles de usuario de la plataforma Our Sour.

## Tecnologías
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Maven

## Funcionalidades previstas
- Registro de usuarios.
- Inicio de sesión.
- Autenticación mediante JWT.
- Autorización basada en roles.
- Gestión de cuentas de usuario.

## Arquitectura
Este microservicio forma parte de la arquitectura de microservicios de Our Sour y se comunica con el sistema a través de un API Gateway.
